## 1. Project Overview
Development of a custom, end-to-end food ordering and management application designed specifically for daily tiffin services. The solution includes distinct portals for customers, kitchen administrators, and delivery personnel.

## 2. Scope of Work

### 2.1. End-User Ordering Portal
A user-friendly interface for customers to interact with your service.
*   **Menu Browsing:** View the available menu for upcoming meals.
*   **Order Placement:** Seamlessly place orders for daily tiffins.
*   **Account Management:** User registration, login, and basic order history.

### 2.2. Admin Panel & Kitchen Management
A centralized dashboard to manage business operations.
*   **Menu Configuration:** Easy-to-use tools to set and update "Tomorrow's Menu".
*   **Kitchen Summary:** A dedicated view aggregating all orders to provide a clear total count of items needed for preparation (e.g., total rotis, total sabzis).
*   **Order Oversight:** View and manage all incoming orders.

### 2.3. Delivery Portal
A streamlined interface for delivery staff.
*   **Delivery Assignments:** View active orders requiring delivery, along with customer addresses.
*   **Status Tracking:** Mark orders as delivered to update the central system in real-time.

## 3. Technology Stack & Hosting
*   **Development:** Modern web technologies ensuring a responsive user experience across both desktop and mobile devices.
*   **Hosting:** The application will be deployed using robust **Free Tier** services (such as Vercel/Netlify for the frontend and Firebase/Supabase for the backend). This ensures **zero recurring monthly hosting costs** while maintaining high availability and performance within standard free tier limits.
